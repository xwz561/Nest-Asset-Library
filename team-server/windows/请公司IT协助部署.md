# 请公司 IT 协助部署小旺仔团队素材库

我们希望在公司局域网共用一个素材库，约 100 人使用，素材总量预计约 10 TB。大家只在小旺仔素材库软件内上传和整理文件；NAS 保存原始文件。公司电脑不能从互联网访问这个服务。

## 已确定

- 服务器：这台 Windows 电脑（需要保持开机并连接公司网络）。
- NAS：S: 对应的公司共享盘。请在共享盘下使用独立目录 **NestTeamLibraryData**，不要把其他文件混放进去。
- 使用人数和规模：约 100 人、约 10 TB。
- 功能：多人可上传、建文件夹、改名、移动和恢复回收站内容；目录变更自动同步。
- 现有聊天功能保持不变。

## 请 IT 准备

1. 在服务器电脑本地磁盘安装并配置 PostgreSQL；数据库文件不要放在 NAS 上。
2. 安装 Node.js 22 或更新版本。
3. 给服务器电脑运行账号开通 NAS 共享读写权限。安装程序会把 S: 转成开机服务可用的网络路径，并创建独立的 **NestTeamLibraryData** 子文件夹。
4. 为服务器电脑名称准备公司内部 HTTPS 证书，并让公司电脑信任公司的证书颁发机构。
5. 只允许公司局域网访问 TCP 43180 端口；不要配置互联网端口转发。
6. 设置 PostgreSQL 和 NAS 的定期备份。首次上线先使用空的测试目录验证上传、预览、目录同步和断线恢复。

## 安装步骤

1. 解压部署包。
2. 双击 windows\Check-TeamLibraryHost.cmd，将检查结果交给 IT。结果不包含密码或私钥。
3. IT 确认 PostgreSQL、Node.js、HTTPS 证书及 NAS 权限已就绪后，双击 windows\Install-TeamLibraryTask.cmd，允许 Windows 管理员提示。
4. 安装向导选择 NAS 共享位置，并输入 IT 提供的数据库连接信息、证书文件路径和首次管理员账号。不要把密码、私钥或连接串发到群聊。
5. 由 IT 在小旺仔素材库软件“团队素材库”页面填写服务器 HTTPS 地址登录。管理员在成员管理中为同事创建账号。

## 上线前确认

- 从另一台公司电脑打开 https://服务器电脑名称:43180/healthz，应显示服务在线。
- 使用空测试目录完成上传、文件夹创建/改名/移动、另一台电脑实时看到变化、预览、下载和回收站恢复。
- 确认备份可恢复后，再开始存放正式素材。

# Nest 本地素材库

一个原创的本地素材管理 MVP，灵感来自现代素材库工作流。

## 已实现

- 图片拖拽和多选导入
- 瀑布流素材浏览
- 名称与标签搜索
- 图片、收藏夹、未分类筛选
- 收藏、标签、备注和重命名
- 素材详情预览与删除
- IndexedDB 本地持久化
- 响应式界面

## 启动

需要 Node.js 20 或更高版本。

```powershell
npm install
npm run dev
```

随后打开终端显示的本地地址。生产构建使用：

```powershell
npm run build
```

启动桌面版：

```powershell
npm run desktop
```

生成 Windows 便携版程序：

```powershell
npm run package:win
```

## 当前边界

当前提供浏览器版，以及 Electron Windows/macOS 桌面版。示例图库已内置，可完全离线使用；用户导入的图片保存在应用的 IndexedDB 中。

## macOS 构建

项目支持 Intel Mac（x64）和 Apple Silicon（arm64）。macOS 安装包必须在 Mac 上构建：

```bash
npm ci
npm test
npm run package:mac
```

产物包括两种架构的 DMG 安装包和 ZIP 免安装包。推送 `v*` 标签后，GitHub Actions 也会在 macOS 运行器上自动构建并上传到对应 Release。当前自动构建未配置 Apple Developer 签名与公证，因此首次打开时可能需要在 Finder 中右键选择“打开”。

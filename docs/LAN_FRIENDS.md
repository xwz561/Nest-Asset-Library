# 局域网好友与私聊（3.0.41）

同一局域网的电脑打开支持此功能的素材库后，会自动出现于“局域网信号”的在线电脑列表，无需填写私聊服务器地址或房间码。现有“聊天”入口的公共群聊仍使用原来的服务连接方式。

## 使用方法

1. 点击“局域网信号”，选择“更换头像”导入本机图片；昵称点击“保存”后生效。头像与昵称同步给在线好友。
2. 点击在线好友打开一对一私聊。输入消息后点击“发送”或按 Ctrl+Enter；点击“发送文件”或直接拖入文件即可传送。
3. 素材卡片右键选择“发送给好友”，再选择在线电脑。多选后右键选中项会发送整个所选集合（最多 50 个素材）。
4. 有素材库时，收到的附件自动进入“接收文件 → 发送者昵称”，立即加入素材列表；实体位置为 `<素材库>/assets/接收文件/<发送者昵称>/<文件>`。没有打开素材库时先保存在聊天缓存，选择素材库后点击“导入当前素材库”。“保存附件”仍可另存；图片支持预览。单个文件最多 10 GB，图片预览最多 25 MB。
5. “打开聊天记录”可查看已有私聊，包括离线好友的历史。未读数显示在在线好友和素材库工具栏。

旧版电脑可被发现，但显示“需更新素材库”；双方升级到 3.0.40 后才能直接私聊和传文件。

## 数据与连接

- 设备身份保存在 Electron userData 的 `lan-signal-settings.json`。当前版本会按操作系统设备标识和本机登录账户 SID 派生稳定 UUID；只保存和广播派生 UUID，不保存或发送原始设备码。升级时本机私聊历史里的旧随机身份会迁移到新身份。私聊记录、头像与未入库附件保存在 `lan-peer-chat` 目录。成功入库并保存聊天归档记录后才清理该附件缓存。入库失败保留缓存并显示原因。
- 同一设备沿用首次建立的发送者文件夹，改昵称后不会把已有文件分散到新目录；同名的不同设备用数字后缀区分。同名不同内容的文件不会覆盖；同一发送者重复发送相同内容会复用已有素材。
- 已归档的聊天附件按素材 ID 查找，因此素材在该库重命名、移动后仍可预览和另存。删除素材或移走整个素材库之后，聊天会提示附件不存在。
- 发现使用 UDP 47483，文本、头像和文件使用 TCP 43128。Windows 安装器通过一个管理员授权的助手配置两条入站规则，限定本地子网、对应端口及当前安装的素材库程序。
- 关闭主窗口到后台后继续接收；从托盘退出时停止通信。关闭轮盘快捷键不影响聊天与文件接收。
- 私聊分别发到目标电脑，其他好友不会收到该消息或附件。入站连接检查来源电脑和当前会话标记，拒绝网页来源和非局域网地址；附件按字节流写入应用缓存，不接受对方指定本机保存路径。
- 接收中断会清理未完成文件；发送时可取消。未实现断点续传，中断后重新发送。

## 验证范围

`test/lan-peer-chat.test.cjs` 验证独立目标、重复请求、未读与持久化、完整文件接收、取消清理、头像同步和旧客户端兼容。`scripts/lan-peer-ui-qa.cjs` 使用隔离 Electron profile、临时素材库及仅回环网络的好友，验证点击私聊、头像、文本往返、图片预览、保存和右键素材发送。

真实 Wi-Fi 多机连接及安装器防火墙授权需要安装候选后实测；测试不会修改正式素材库或正式安装。

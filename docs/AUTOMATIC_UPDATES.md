# 后台自动更新（3.0.41）

“偏好设置 → 更新 → 后台自动更新”默认开启，各电脑可单独关闭。检查与下载运行在 Electron 主进程：启动约 5 秒后检查一次，其后每 30 分钟检查 GitHub 最新正式 Release。关闭主窗口只隐藏到后台，下载仍继续。

## 安装时机与范围

- Windows 当前用户安装版：安装器记录 `CurrentUser` 范围，下载完成后在托盘“退出”或下次启动时静默安装。下次启动安装后重开程序；托盘退出时升级完成后不主动重开。
- Windows 单文件版：下载对应 Portable 包，退出后替换当前文件并保留 `.old` 回退副本。
- Windows 所有用户安装或无法识别范围：后台下载，界面提示手动安装；安装器可能需要管理员授权。
- macOS：按 Apple Silicon/Intel 选择 DMG，后台下载后提示手动安装，不尝试覆盖运行中的应用。
- 开发运行：不进行周期检查或自动覆盖；可以手动检查下载。真实安装后启用自动流程。

首次需要手动安装含此功能的 3.0.41；之前的版本无法通过这次源码修改直接获得后台安装能力。此候选尚未发布 GitHub，因此还不会被其他电脑自动检测到。

## 下载与数据

更新仅接受项目官方 Release 包及 GitHub 提供的 SHA256 摘要，下载完成、安装前、独立助手安装前各校验一次。安装版/单文件版不互相替换。下载中断保留 `.part`，下次尝试以 Range 继续；服务器不支持续传时重新下载。

设置与下载记录位于 userData 的 `updates`。关闭开关暂停自动下载，保留已下载片段；重新打开可继续。已下载包也只有在开关开启时才会自动安装，手动安装仍可使用。

退出安装前等待素材修改保存。导入、库写入、好友文件传输或文本编辑未结束时推迟升级。安装助手等旧进程退出后执行 `/S /currentuser --updated /D=当前安装目录`，保留素材与应用数据，静默升级保留已有防火墙规则。一次自动安装失败不会在每次启动循环重试，设置页会提示手动重试。

## 验证边界

单元验证使用临时目录、内存更新包和模拟安装助手。PowerShell 替换验证只覆盖临时字节文件，不运行正式安装器。隔离 Electron 验证设置开关、保存确认和附件归档，不修改正式安装及真实素材库。实际当前用户安装升级、macOS 安装和真实多机 Wi-Fi 仍需要候选实测。

# 3.0.30 现成组件界面改造

目标：保留现有 Electron 数据及 IPC，用 Fluent UI 统一主界面；TagSpaces MIT 公共模块复用文件路径/格式/文件名标签解析；媒体用 Electron DAM 同款 WaveSurfer.js 与 Video.js。用户已确认这一替代方案并允许后续自行推进，不重复要求审核。

MVP范围：主界面按钮、文件夹树操作、搜索/导入区域、素材卡片、详情面板；现有聊天、恶搞视频、AI Flow入口不删除。媒体播放器仅在选中的详情/大预览使用，避免5000个素材创建播放器。缩略音频继续使用原缓存和单一播放管理器。

默认Eagle灰，统一间距/控件尺寸/焦点。顶部宽度不足换行，不浮盖素材；详情栏独立占位。移除导入区像素风覆盖和重阴影。TagSpaces只读取，不用其写入代码改真实路径；显示扩展名和可选文件名标签。播放器错误显示本地提示，卸载释放资源，不自动发外部请求。

所有试验只在临时源码与浏览器临时配置、本地QA素材进行。保留原源码和原安装包。新构建通过后，备份精确受影响文件再同步源码；若有依赖/部署阻塞明示。

验收：已有310测试；文件名/路径解析边界、播放器卸载和错误反馈；本地浏览器界面截图及窗口1280/1440/1920、详情开关；生产构建；未实测安装版明确标记。

# 深度视频转换器

Windows 桌面工具：将普通视频逐帧估算为灰度深度、伪彩深度、白模动画或伪三维模型，可反转近远，并可选择保留原音频或静音输出。白模动画根据深度表面法线生成白色黏土/石膏式立体光影；伪三维模型加入冷灰材质、环境遮蔽、轮廓高光和动态棚拍灯光。转换成功后会自动打开输出文件夹并选中生成的视频。

小旺仔出品。

## 使用

1. 启动窗口版 `DepthVideoConverterV2.exe`（不会出现黑色命令行窗口）。
2. 将视频直接拖到“输入视频”文本框，或点击“浏览”选择；再选择输出 MP4。启动时自动填入程序同目录的 `depth-anything-v2-small-quantized.onnx`，也可点击模型“浏览”更换。找不到推荐模型时，仅有一个 ONNX 文件则自动选择；多个候选时需手动选择。
3. 选择输出样式和是否反转；如需静音，勾选“不要视频声音（静音输出）”。
4. 点击“开始转换”。

兼容固定或动态输入尺寸的 MiDaS/DPT 类 ONNX 模型。程序默认使用 ImageNet 均值/方差归一化；不同预处理规范的模型可能需要调整源码。

## 从源码构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

构建结果包括窗口版 `dist\DepthVideoConverterV2.exe` 和供其他程序调用的 `dist\DepthVideoConverterCLI.exe`。构建脚本优先使用本目录 `.venv` 环境，安装依赖并将 FFmpeg 嵌入 EXE。将模型文件放在 EXE 同目录即可自动识别；也可手动选择其他模型。
